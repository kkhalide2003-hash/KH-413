# KH Floating Launcher

تطبيق Android بفقاعة عائمة للوصول السريع إلى التطبيقات.

## البناء على GitHub

1. ارفع محتويات هذا المشروع إلى Repository جديد.
2. افتح تبويب **Actions**.
3. اختر **Build KH Launcher APK**.
4. اضغط **Run workflow** أو ادفع الملفات إلى `main`.
5. بعد انتهاء البناء افتح الـ workflow ثم **Artifacts** وحمّل `KH-Launcher-debug`.

## المزايا

- فقاعة KH عائمة فوق التطبيقات.
- سحب الفقاعة إلى أي مكان.
- الضغط على الفقاعة يفتح قائمة التطبيقات.
- تصميم أسود داكن + ذهبي.
- شاشة مقدمة: صنع من قبل Khalid Ouassi.
- صلاحية الظهور فوق التطبيقات.
- يعمل من Android 6.0+.

> ملاحظة: هذا الإصدار يفتح التطبيقات بسرعة ولا يضع واجهات التطبيقات الأخرى داخل نوافذ مستقلة؛ ذلك يعتمد على قيود Android ودعم كل تطبيق.
